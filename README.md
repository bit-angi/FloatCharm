## 基本功能需求 ## 

- 文件操作
 打开文件：用户可以通过菜单或快捷键打开已存在的流程图文件。系统应支持常见的流程图文件格式。
 文件编辑：打开的文件可以直接在软件中进行编辑，包括添加、删除、修改图形元素和文本。
 另存文件：用户可以将当前编辑的流程图保存为新文件，支持多种文件格式,包括png,fct,svg格式。

- 编辑操作
 复制、粘贴、剪切：用户可以对选中的图形元素或文本进行复制、粘贴和剪切操作。这些操作支持快捷键（如Ctrl+C, Ctrl+V, Ctrl+X）。
 工具栏快捷键：常用功能应在工具栏中提供快捷按钮，并支持键盘快捷键操作。
 撤销重做：系统提供多级撤销和重做功能，允许用户回退或重复之前的操作。

- 绘图功能
 基本图形绘制：支持绘制矩形、圆形、椭圆、圆角矩形、平行四边形、三角形、梯形、线条、箭头等基本图形元素。
 图形操作：用户可以对绘制的图形进行平移和缩放操作。
 区域操作：支持选择多个图形元素进行批量操作，如移动、删除、复制等。

- 注释和标签
 文本添加：允许用户为图形元素添加文本注释或标签。
 文本编辑：支持对已添加的文本进行编辑、格式化（如字体、大小、颜色）。

- 元素库
 预设元素：提供流程图常用元素，如开始节点、结束节点、子流程等。
 自定义元素：允许用户创建和保存自定义图形元素。

- 属性编辑
 元素属性：用户可以编辑图形元素的详细属性，如大小、颜色、线条样式等。
 文本属性：支持编辑文本的字体、大小、颜色、对齐方式等。

- 交互功能
 拖拽操作：支持通过鼠标拖拽来移动和调整图形元素。
 连线功能：允许用户在不同节点之间创建连接线，支持直线、曲线、箭头等样式。
## 可选功能需求 ##
- 模板功能
 预设模板：提供多种常用流程图模板供用户选择。
 自定义模板：允许用户保存自己创建的流程图为模板，以便复用。

- SVG导出
 导出功能：支持将流程图导出为SVG矢量图格式。
 质量控制：确保导出的SVG文件保持高质量，支持缩放而不失真。

- 智能连接
 自动吸附：线条和箭头在靠近图形元素时自动吸附到合适的连接点。
 路径优化：自动调整连接线路径，避免与其他元素重叠。

- 图形旋转
 自由旋转：90度旋转任何图形元素。
 角度控制：提供精确的角度控制，支持输入具体旋转角度。

- 文本搜索和替换
 全局搜索：支持在整个流程图中搜索指定文本。
 替换功能：允许用户批量替换搜索到的文本。
 高亮显示：搜索结果在图中高亮显示，便于定位。
